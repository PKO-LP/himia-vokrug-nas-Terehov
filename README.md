# Химия вокруг нас
Простой сайт из двух страниц для изучения химических элементов.
## Файлы проекта
- `index.html` — таблица химических элементов Д. И. Менделеева.
- `elements.html` — список из 11 элементов (номер, символ, название, свойства, применение).
- `PLAN.md` — план обновления проекта и отчёт о проверке отката.
## Запуск
Скачайте файлы и откройте `index.html` в любом браузере (для загрузки таблицы нужен интернет).
